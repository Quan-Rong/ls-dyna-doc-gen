## [2.1.0] - 2026-02-12

### Changed

- **界面布局优化**: 改进主窗口布局，使用 QSplitter 实现可调整的分隔条
  - 拖动窗体左边缘可以调整中部内容显示栏的宽度
  - 拖动窗体右边缘可以调整最右边 LS-Dyna 命令列表栏的宽度
  - 左侧文件列表栏保持固定宽度，不参与拖动调整
  - 改进了用户体验，允许用户根据需求自定义各栏宽度

### Fixed

- **处理完成后内容丢失问题**: 修复了文件处理完成后三个标签页（检查清单、详细文档、概览文档）内容丢失的问题
  - 问题：处理完成后，标签页内容被清空
  - 原因：列表更新时选择状态丢失，触发选择变化信号发出 None
  - 解决：使用 `blockSignals` 在更新列表时临时阻止信号，保存并恢复选择状态

### 影响范围

- **GUI 界面**: `gui_app/gui/main_window.py` - 布局结构调整
- **GUI 界面**: `gui_app/gui/file_list.py` - 列表更新逻辑优化

### 升级说明

- 无需特殊操作，直接使用新版本即可
- 界面布局更加灵活，用户可以根据需要调整各栏宽度

## [2.0.0] - 2026-02-12

### Added

- **新架构设计**: 建立全新的 GUI 架构，包含以下模块：
  - `gui/`: GUI 界面模块
    - `main_window.py`: 主窗口
    - `file_list.py`: 文件列表组件
    - `content_view.py`: 内容显示组件
    - `checklist_view.py`: 检查清单视图
    - `document_view.py`: 文档查看视图
  - `controller/`: 业务逻辑控制器
    - `file_controller.py`: 文件处理控制器
    - `document_controller.py`: 文档生成控制器
    - `checklist_controller.py`: 检查清单控制器
  - `models/`: 数据模型

    - `document_model.py`: 文档数据模型
    - `checklist_model.py`: 检查清单数据模型
