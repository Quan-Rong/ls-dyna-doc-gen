# 🚀 GitHub_Sync 快捷脚本使用说明

为了简化代码备份任务，本项目包含了一个名为 `Github_Sync.bat` 的快捷脚本。它能让你在完成代码修改后，只需一键点击即可将最新的改动同步到 GitHub。

## 📖 如何使用？

### 方式 A：默认同步（最快）

1. **双击运行** `Github_Sync.bat`。
2. 脚本会自动将**所有改动**暂存、提交并推送到 GitHub。
3. 默认的提交信息（Commit Message）是当前的日期和时间。

### 方式 B：自定义提交信息（更严谨）

如果你想给这次更新起一个特别的名字（例如"修复了解析错误"），你可以通过命令行运行：

1. 在当前目录打开终端（Cmd 或 PowerShell）。
2. 输入命令：

    ```bash
    .\Github_Sync.bat "这里写你的更新描述"
    ```

## ⚙️ 脚本逻辑说明

该脚本会自动执行以下 Git 标准工作流：

1. `git add .` ：扫描所有改动的文件（已配置 `.gitignore`，Input 和 Output 文件夹会被自动忽略）。
2. `git commit -m "..."` ：记录改动说明。
3. `git push origin main` ：将本地记录上传到云端仓库。

## ⚠️ 注意事项

1. **网络连接**：运行脚本时请确保电脑可以访问 GitHub。
2. **数据安全**：本工具已配置为**忽略** `Input` 和 `Output` 目录。这是为了防止庞大的工程文件占用仓库空间并导致泄密。如果你需要备份特定的 `.key` 文件，请手动上传或将它们从 `.gitignore` 中移除。
3. **身份认证**：初次运行同步时，可能会弹出浏览器窗口要求你登录 GitHub。登录成功后，Windows 会记住你的身份凭据，下次运行将完全自动化。

## 🛠️ 常见问题

**Q: 运行后报错 "git is not recognized..."**
A: 请确保你的电脑已安装 [Git for Windows](https://git-scm.com/) 并已添加到环境变量（PATH）。

**Q: 提交失败并提示 "rejected"**
A: 这通常是因为 GitHub 上的版本比你本地新（例如你在另一台电脑上改了代码）。请先在终端运行 `git pull origin main` 同步云端代码到本地。
